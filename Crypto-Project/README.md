# GameVault DBMS 

## Instructions
### Node.js along with Node Package Manager "npm" installed in order to operate the server.
1. Have DB Browser to browse the sqlite database
2. Go to RAWG API's website, sign in and acquire a free API key.
3. In vscode, open the folder and go to the .env file where the API key needs to be added.
4. If database file is empty, Run the scripts to populate the database. A users script can be run to have premade users to easily login.

#### Commands:
```
npm run seed-users
npm run seed-games
npm start
```
